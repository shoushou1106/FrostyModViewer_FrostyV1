# Frosty Mod Viewer
Cross-platform native app to view [Frosty v1](https://github.com/CadeEvs/FrostyToolsuite) mods anywhere. Supports iOS and Android as initial plan.

# About

This is a project I started in Late 2023. The repo basically is a empty Android template with no real content. The idea struck while I was managing a QQ group when preventing people sending cheat mods. I want an app that can view mod description on my phone. The idea will be bring to the cross-platform Frosty v2 for the Mod Preview install Window.
